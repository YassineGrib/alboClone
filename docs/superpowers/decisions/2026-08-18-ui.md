# Decision: UI direction

**Date:** 2026-08-18  
**Status:** settled (user: "with minimalist light/dark ui" at shared-understanding gate)

Depends on: `2026-08-18-identity-and-client.md`

## Settled

1. **Look:** utilitarian minimalist. Editorial, type-first, lots of space. Not a colorful social app.

2. **Theme:** light and dark, both first-class. Default follows the OS. User can force Light, Dark, or System from the same screen as the API URL.

3. **Color:** one ink accent (near-black in light, near-white in dark). Status chips use muted pastels only. No gradients, mesh blobs, glassmorphism, or purple.

4. **Shape:** 8px corners on fields and buttons. Pills only for tiny status chips.

5. **Type:** platform UI fonts (SF Pro on iOS, system on Android). No Inter / Roboto-as-brand / emoji in the UI.

6. **Motion:** almost none in slice 1. List updates, no hero animations.
