# Decision: v1 scope, audience, offline

**Date:** 2026-08-18  
**Status:** settled (grill round 1, user accepted recommendations)

## Settled

1. **v1 is a thin vertical, not the full Albo MVP.**  
   Login + paste a URL + list + visible `pending` / `ready` / `failed`.  
   Out of v1: share sheet, collections, map, collab, TikTok/Instagram import, IAP, store listing.

2. **First user is you (maybe 1–2 friends).**  
   Sideload / internal only. No App Store, Play Store, or subscriptions.

3. **Offline-first starts on day 1 of the first slice.**  
   Write the save locally first (Drift). Show sync status. Never drop a save if the API is down.  
   Not a full sync engine. Local row + status chip is enough.

## Overrides `albo-clone-technical-plan.md`

- Section 2 MVP list is a **roadmap**, not the first ship.
- Phase 7 "offline as polish" is **rejected**. Offline is a first-slice constraint.
- Monetization / import quotas are **not in scope** until a later grill.
